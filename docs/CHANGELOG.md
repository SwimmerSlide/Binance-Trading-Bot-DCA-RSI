# Changelog

## [3.0.0] - 2025-01-25

### Added
- Scalping strategy with Bollinger Bands + EMA crossover
- Grid trading strategy with configurable levels
- Bybit exchange support
- WebSocket real-time data feed
- Order book depth aggregation
- ATR-based stop loss/take profit

### Changed
- Migrated to .NET 9
- Improved risk management with daily loss limits
- Refactored indicator calculations

## [2.0.0] - 2024-10-01

### Added
- MACD strategy with crossover detection
- DCA (Dollar Cost Averaging) strategy
- Position management and PnL tracking
- Telegram notifications
- Multiple trading pairs support

## [1.0.0] - 2024-06-15

### Added
- Initial release
- RSI strategy (oversold/overbought)
- Binance API integration
- Basic order execution
- Configuration file support
